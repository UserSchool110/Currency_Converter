
# Currency Converter - Конвертер валют

## Информация об авторе
**Имя и фамилия:** Кобликов Артём
**Дата создания:** Апрель 2026

## Описание программы

**Currency Converter** - это GUI-приложение для конвертации валют с использованием актуальных курсов из внешнего API. Приложение позволяет конвертировать суммы между различными валютами, сохранять историю конвертаций в формате JSON, а также загружать сохранённую историю.

### Возможности:
- Конвертация валют (USD, EUR, GBP, JPY, CNY, RUB)
- Получение актуальных курсов из внешнего API (exchangerate-api.com)
- Сохранение истории в JSON-файл
- Загрузка истории из JSON-файла
- Удаление выбранной записи из истории
- Очистка истории
- Поверка на корректность

## Инструкция по запуску

### Требования:
- Python 3.6 или выше
- Установленная библиотек

### Запуск:
1. Откройте терминал или командную строку
2. Перейдите в директорию проекта:
   ```bash
   cd currency_converter
   ```
3. Запустите приложение:
   ```bash
   python currency_converter.py
   ```

## Примеры использования

### Конвертация:
1. Введите сумму в поле "Сумма:"
2. Выберите валюту "Из:" (например, USD)
3. Выберите валюту "В:" (например, EUR)
4. Нажмите кнопку **"Конвертировать"**
5. Результат появится на экране, запись добавится в историю

### Управление историей:
- **Очистить** - удаляет все записи истории
- **Сохранить** - сохраняет историю в файл `history.json`
- **Загрузить** - загружает историю из файла `history.json`

### Тестовые данные (примеры для проверки):

Попробуйте выполнить следующие конвертации:

| Сумма | Из валюты | В валюту |
|-------|-----------|----------|
| 100 | USD | EUR |
| 50 | EUR | RUB |
| 1000 | JPY | USD |

После выполнения попробуйте:
- Сохранить историю в JSON, закрыть приложение, затем загрузить обратно
- Очистить всю историю
- Ввести отрицательное число для проверки валидации

## Валидация данных

Приложение проверяет:
- Поле суммы не должно быть пустым
- Сумма должна быть положительным числом
- При очистке всей истории требуется подтверждение
